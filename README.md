# Website-builder — Aura Studio

Aura Studio is a high-performance visual website builder and instant site publishing engine inspired by Webflow and Shopify. It features a dark neumorphic UI (Emerald & Teal), 50+ modern production-ready website templates, responsive breakpoint switching, real-time code export, and zero-configuration instant static site hosting.

---

## ✨ Features

- **Visual Drag & Drop & Hierarchy Canvas**: Edit elements, nest containers, rearrange layers, and customize styles with live visual feedback.
- **50+ Complete Full-Website Templates**: Built-in modern templates spanning SaaS, E-Commerce, Portfolios, Agencies, Web3, Education, Healthcare, Hospitality, Fitness, and more.
- **Responsive Design System**: Seamless toggling between Desktop, Tablet, and Mobile viewports with adaptive layouts and automatic mobile drawer navigation.
- **Instant Site Publishing**: Publish any website project to an instant live URL (`/live/:siteId`) with working forms, interactive accordion FAQs, and mobile responsive menus.
- **Dark Neumorphic Aesthetic**: Designed with an emerald green (`#10b981`), teal (`#14b8a6`), and crisp white palette on deep dark neumorphic surfaces (`#0a1010`, `#0d1414`).
- **Clean Code Export**: Export clean semantic HTML/CSS, React (Tailwind), or pure JSON schemas with one click.
- **History & Revision Engine**: Undo, redo, project saves, and multi-page management stored locally with persistence.

---

## 🛠️ Tech Stack

- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS + Custom Neumorphic Design System
- **Icons**: Lucide React
- **Build Tool**: Vite 6

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Abhishekverma657/Website-builder.git
cd Website-builder
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open `http://localhost:3000` in your browser.

### 4. Build for production
```bash
npm run build
```
